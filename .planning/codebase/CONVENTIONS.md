# Code & Markup Conventions

## HTML & Alignment
- Alignment using HTML container attributes: `<div align="center">`, `<h1 align="center">`, `<h2 align="center">`.
- Section dividers using `<hr/>` and spacing using `<br/>`.

## Badge Styling
- Shield Badges: `style=for-the-badge`.
- Theme colors: `react` theme used for stats and top languages cards.
- Rounded borders: `border_radius=10`.
